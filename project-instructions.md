# Project Instructions

- Prefer Shopify-native theme features over custom abstractions.
- Preserve theme-editor configurability and existing storefront behavior unless asked to change it.
- Use semantic, accessible HTML and progressive enhancement.
- Keep Liquid simple; move repeated presentation fragments to snippets and reusable content to blocks when appropriate.
- Keep JavaScript small, scoped, and resilient to section/block re-rendering when relevant.
- Respect the existing CSS/SCSS architecture; do not introduce a new system without clear value.
- For reviews, cite exact paths and prioritize real defects over style preferences.
- For edits, avoid unrelated changes and run existing Theme Check/lint/test/build commands when available.
- Include a concise Git commit message when code changes.
