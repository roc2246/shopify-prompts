# Deep Review Checklist

- Theme architecture and correct file responsibility
- Liquid correctness, escaping, loop cost, snippet inputs
- Section/block schema validity and stable IDs
- JSON template/section-group composition
- Merchant editor usability and dynamic content support
- JS progressive enhancement and editor re-render behavior
- CSS scope, responsiveness, duplication, cascade risk
- Semantic HTML, focus, keyboard, labels, media alt behavior
- Asset loading, responsive media, avoidable render blocking
- Dead code, duplicated logic, fragile coupling
