# Architecture Checklist

- Standard theme directory responsibilities
- JSON template and section-group composition
- Layout limited to true global shell concerns
- Reusable snippets vs merchant-configurable blocks/sections
- Stable config/schema contracts
- Locale coverage and no duplicated hard-coded UI text
- Source-vs-compiled asset boundaries
- No unnecessary build complexity
- Avoid giant sections/snippets with mixed responsibilities
- Reasonable dependency direction and discoverability
