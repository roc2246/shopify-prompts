# Performance Checklist

- Repeated Liquid work/loops and oversized rendered DOM
- Render-blocking CSS/JS and unnecessary global assets
- Route/section-specific loading opportunities
- Responsive images, dimensions/aspect ratios, lazy/eager priority
- Font loading and avoidable variants
- Duplicate libraries/polyfills
- Long-running listeners/observers and layout thrashing
- Third-party scripts and app embeds
- CLS sources and above-the-fold resource priority
- Existing Theme Check/Lighthouse evidence when supplied
