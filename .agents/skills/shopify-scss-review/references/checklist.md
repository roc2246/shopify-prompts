# SCSS Checklist

- Source/compiled boundary understood
- Mobile-first responsive rules
- Shallow selectors and predictable specificity
- Section/component scope safe under merchant composition
- Shared tokens for genuine recurring values
- Mixins/functions/maps only for repeated logic
- Avoid deep nesting, `@extend` coupling, and duplicate declarations
- CSS custom properties when runtime theming/settings require them
- No JS-dependent styling when CSS suffices
- Build entrypoints/import order and output path are clear
