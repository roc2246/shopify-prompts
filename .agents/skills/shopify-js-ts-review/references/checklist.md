# JS/TS Checklist

- Works with multiple section instances
- Safe selectors and null handling
- No accidental duplicate listeners
- Theme editor section/block lifecycle handled when needed
- Keyboard/focus behavior for custom interactions
- Progressive enhancement/fallback behavior
- Minimal global state and side effects
- No unnecessary dependencies/polyfills
- Defer/lazy interaction work when possible
- Type external/DOM boundaries; avoid `any` leaks
