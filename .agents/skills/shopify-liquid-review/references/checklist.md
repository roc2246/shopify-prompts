# Deep Liquid Checklist

- Syntax and Theme Check issues
- Correct object scope and nil/blank handling
- Avoid repeated filters/lookups in loops
- `render` with explicit inputs; no hidden coupling
- Safe output/escaping for text and attributes
- Correct Shopify forms/routes/URLs
- Responsive image/media usage
- Translation keys for reusable storefront strings
- No hard-coded merchant content that belongs in settings/blocks
- Clear variable names and low nesting
