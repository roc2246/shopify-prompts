# Section/Block Checklist

- Clear merchant purpose and editor labels
- Minimal settings; sensible defaults/ranges
- Stable setting/block IDs
- Presets where useful
- `enabled_on`/`disabled_on` only when meaningful
- Blocks for repeatable/reorderable units, not arbitrary abstraction
- Dynamic sources compatible where appropriate
- Accessible semantic output
- Section-scoped behavior/styles
- Theme editor add/remove/reorder/re-render behavior
