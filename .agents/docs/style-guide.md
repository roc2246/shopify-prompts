# Storefront Style Guide

Prioritize readable content, clear hierarchy, accessible interactions, consistent spacing, and stable responsive layouts.

- Use a consistent container strategy and spacing scale.
- Preserve visible focus states.
- Ensure controls remain usable by keyboard and touch.
- Prevent avoidable layout shifts with explicit media dimensions/aspect ratios.
- Use responsive images and avoid oversized decorative assets.
- Prefer CSS for presentational behavior; use JavaScript only when interaction requires it.
- Keep section-specific styles scoped enough to avoid merchant-composition conflicts.
